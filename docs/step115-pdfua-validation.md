# Step 115 — Chromium sample validation (NO-GO)

## Scope and reproducibility

Validated the synthetic English and Bangla PDFs generated by the Step 115 backend CI run [36377478337](https://github.com/atikas20152075/Ai-Writing/actions/runs/36377478337), commit `7767a909c335a1b82a1b8a157fe54b802f718a3f`. The short-lived CI artifact is named `step115-bilingual-pdf-samples`. It contains `report-en.pdf` and `report-bn.pdf`; no learner information is included.

Installed the stable veraPDF Greenfield CLI 1.30.2 and validated each PDF with both built-in profiles (`--flavour ua1` and `--flavour ua2`). All four validations failed:

| Sample | Profile | Failed checks | Findings |
|---|---:|---:|---|
| English | PDF/UA-1 | 1 | Required XMP metadata stream is missing. |
| English | PDF/UA-2 | 6 | Missing PDF 2.0 namespace on the Document structure element; missing XMP metadata; four outline destinations are not structure destinations. |
| Bangla | PDF/UA-1 | 87 | Missing XMP metadata; 86 glyph mappings contain invalid Unicode values (zero, U+FEFF, or U+FFFE). |
| Bangla | PDF/UA-2 | 92 | Missing PDF 2.0 namespace; 86 invalid glyph mappings; four outline destinations are not structure destinations; missing XMP metadata. |

The PDFs are tagged according to Poppler `pdfinfo`, and a rendered-page spot check showed readable visual shaping. Those facts do not remedy the validation failures. Poppler's raw text stream also inserts spaces inside Bengali words, and its structure-tree dump splits Bangla text into short fragments. This extraction/structure behavior needs review with actual assistive technology and a Bangla expert.

## Decision

The Chromium output is **not PDF/UA compliant**. The Bangla ToUnicode failures are substantive and resemble the prior renderer candidate's mapping problem; do not claim accessible tagged PDFs or release this candidate for real learner reports. Fix metadata, structure namespaces, outline destinations, and especially Bengali glyph-to-Unicode mapping, then repeat validation on generated English and Bangla outputs. Independent screen-reader/accessibility-API review and expert Bangla review remain outstanding. Keep production **NO-GO**.

The CI artifact-generation change exists to make these renderer outputs reproducibly available for investigation. It does not change the release gate or convert any validator result into a pass.
